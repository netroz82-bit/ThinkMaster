# هوش مصنوعی استاد جلالی — بستهٔ PWA برای PWABuilder

این پوشه یک PWA (Progressive Web App) کامل و آمادهٔ ساخت APK با PWABuilder است.

## محتویات پوشه
- `index.html` — خود برنامه
- `manifest.json` — مشخصات اپ (نام، آیکون‌ها، حالت نمایش)
- `sw.js` — service worker برای کارکرد آفلاین پوستهٔ برنامه
- `icons/` — مجموعه کامل آیکون‌ها (شامل نسخهٔ maskable برای اندروید)

## چرا PWABuilder به‌جای AppsGeyser؟
AppsGeyser یک WebView خام (بدون Chrome واقعی) می‌سازد که بعضی قابلیت‌های مرورگری (مثل دانلود فایل یا برخی درخواست‌های شبکه) را کامل پشتیبانی نمی‌کند.
PWABuilder به‌جاش یک TWA (Trusted Web Activity) می‌سازد که از موتور واقعی Chrome روی گوشی استفاده می‌کند — یعنی همه‌چیز دقیقاً مثل خود مرورگر کروم کار می‌کند.

## مرحلهٔ ۱: میزبانی این پوشه روی یک آدرس HTTPS
PWABuilder به یک لینک زندهٔ HTTPS نیاز دارد (نه فایل روی گوشی). ساده‌ترین راه، GitHub Pages رایگان است:

1. یک حساب رایگان در github.com بساز (اگر نداری)
2. یک مخزن (Repository) جدید بساز، مثلاً با نام `master-jalali-ai`
3. تمام فایل‌های داخل همین پوشه (`index.html`, `manifest.json`, `sw.js`, پوشهٔ `icons`) را در ریشهٔ همان مخزن آپلود کن (دکمهٔ "Add file" → "Upload files")
4. برو به Settings مخزن → بخش Pages → از قسمت Source گزینهٔ "Deploy from a branch" را انتخاب کن، شاخهٔ `main` و پوشهٔ `/ (root)` را بزن و Save کن
5. بعد از چند دقیقه، آدرسی شبیه این فعال می‌شود:
   `https://USERNAME.github.io/master-jalali-ai/`

## مرحلهٔ ۲: ساخت APK با PWABuilder
1. به آدرس **pwabuilder.com** برو
2. آدرس GitHub Pages بالا را در کادر وارد کن و Start را بزن
3. PWABuilder به‌صورت خودکار manifest و service worker را بررسی می‌کند — باید همه‌چیز سبز باشد
4. روی "Package For Stores" بزن، سپس گزینهٔ **Android** را انتخاب کن
5. تنظیمات پیش‌فرض معمولاً خوب‌اند (Package ID را اگر خواستی عوض کن)، دکمهٔ Generate را بزن
6. فایل zip دانلودشده را باز کن — یک فایل `.apk` (یا `.aab`) داخلش هست که مستقیم قابل نصب روی گوشی اندرویده

## نکات مهم
- چون بخش گفتگو/تصویر به سرویس‌های هوش مصنوعی خارجی (Gemini یا سرویس سفارشی) وصل می‌شود، service worker عمداً این درخواست‌ها را کش نمی‌کند — همیشه به اینترنت نیاز دارند.
- تنظیمات API (کلید، آدرس) روی خود دستگاه ذخیره می‌شود؛ بعد از نصب اپ باید یک‌بار از داخل برنامه به بخش تنظیمات بروی و دوباره واردشان کنی.
- اگر بعداً محتوای `index.html` را عوض کردی، باید همان فایل را دوباره در GitHub آپلود (Upload) کنی و منتظر بمانی PWABuilder نسخهٔ تازه را بگیرد.
